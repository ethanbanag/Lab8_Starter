Graceful degradation means a website keeps working even when things go wrong. Service workers do this by handling the bad internet connections. If the internet goes out, the service worker can catch the error and is able to load the saved files from the cache. Instead of the website completely breaking, it gracefully (hence the name) steps down into a working offline app.
